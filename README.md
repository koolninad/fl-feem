# fl-feem

Sonic [Fee Monetization](https://docs.soniclabs.com/funding/fee-monetization)
metadata for the `fl` arbitrage executor.

- `metadata.json` — the project metadata the FeeM registration points at
- `icon.png` — 200×200 project logo

Both are served over HTTPS from `raw.githubusercontent.com`, which is what the
registration requires.
